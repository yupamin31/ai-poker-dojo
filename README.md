# ♠ AIポーカー道場

遊びながらポーカー(テキサスホールデム)を学べるWebアプリ。AI相手に実戦しながら、
エクイティ(勝率)・ポットオッズ・ハンドレンジといった現代ポーカーの考え方を
リアルタイムの学習パネルで確認できます。**回収率100%超え**が目標です。

## デモ

GitHub Pagesで公開後、ブラウザからそのまま遊べます。

## 起動方法

ブラウザで `index.html` を開くだけで動きます(サーバー不要・外部通信なし)。

ローカルサーバーを使う場合:

```bash
cd ai-poker-dojo
python3 -m http.server 8399
# → http://localhost:8399 を開く
```

## 機能

### ゲームタブ
- **AI対戦** — 性格の違うAI(タイトAG「健太」/ ブラフ多め「剛」/ ルース「さくら」)と1〜3人で対戦。ノーリミットホールデム、サイドポット対応
- **学習パネル**
  - エクイティを2通り表示: **vs ランダム** / **vs 推定レンジ**
  - 計算方式を明示: ターン・リバーのヘッズアップは**完全確率計算(全探索)**、それ以外は**モンテカルロ法**
  - ポットオッズ(必要勝率)の計算式を毎回表示
  - ドロー / アウツと2倍4倍ルールの概算
  - 推奨アクションと理由(簡易コーチ)
  - **相手のレンジ予想** — AIのアクションに応じて13×13グリッドをリアルタイム更新
- **ハンド読みチャレンジ** — ショーダウン直前に相手のハンドの強さを予想して読みの精度を鍛える

### 学習タブ
- レッスン8本(役の強さ / ポジション / ポットオッズ / エクイティ計算 / ハンドレンジ / GTOとエクスプロイト / ポーカーAIの歴史(Libratus・Pluribus・CFR) / 回収率とバンクロール管理)
- **エクイティクイズ** — ランダムな状況の勝率を当てる(答えは全探索/モンテカルロで計算)
- **役判定クイズ** — 7枚から最強の役を当てる

### 成績タブ
- **回収率**(投資チップに対する回収チップの割合)・収支・VPIP・ショーダウン勝率
- バンクロール推移グラフ
- ハンド読み・クイズの的中率
- 成績は localStorage に保存(ブラウザを閉じても保持)

## 実装メモ

| ファイル | 内容 |
|---|---|
| `js/poker.js` | カード表現、7枚役判定(直接評価)、エクイティ計算(全探索+モンテカルロ)、Chenフォーミュラ、ドロー検出 |
| `js/ai.js` | AI性格パラメータ、意思決定(モンテカルロ勝率ベース)、レンジモデル(アクションによる絞り込み) |
| `js/game.js` | ゲームエンジン(ブラインド、ベッティングラウンド、サイドポット、ショーダウン) |
| `js/app.js` | UI描画、学習パネル、統計、クイズ |
| `js/content.js` | レッスン・用語集コンテンツ |

- 役判定: 約20万回/20ms(全探索エクイティにも十分な速度)
- ターンの全探索は約45,000通りを列挙(1対1)
- レンジ推定は簡易モデル(チェン値バンド+ボードとの絡みで重み更新)であり、GTOソルバーではありません
